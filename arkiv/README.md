# Arkiv

`course-fysikk1-med-regneoppgaver.js` er Fysikk 1-kurset slik det var før appen ble lagt om til pugging av formler, begreper, symboler og definisjoner. Den inneholder alle regneoppgavene (talloppgaver med tilfeldige tall, flervalgsoppgaver med tallsvar og kapitteltest-oppgavene med utregning). Filen lastes ikke av appen, men kan brukes når regneoppgavene skal tas inn igjen.
